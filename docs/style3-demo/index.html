研究生自我管理系统

读研的日子过得很快 —— 快到一恍惚，一周就没了。
忙到晚上躺下，想不起今天到底推进了什么。

这个工具不让你更努力。
它只让你做过的事，留得下来。

记住的是做过的事，
不是「够不够努力」。

—— 写在页边

一天的记录长这样 ——


07:30 		打卡开始 　选好项目，按下「开始上班」

12:40 		一段完整的工作时段 　自动记进今日时段，附产出备注

17:00 		收工提醒 　浮出面板：今日汇总 + 还没做完的待办

17:05 		恭喜下班 🎉 　彩纸落下，今天的事都留下来了

它记什么

⏱ 工作与休息

双态计时，挂项目标签，写产出。
休息段单独统计 —— 休息也是记录的一部分。

🚩 科研看板

计划 / 进行中 / 卡住 / 完成。
卡住时写下阻塞原因与下一步动作。

✅ 待办

@项目 !日期 语法，拖拽排序，优先级三档。

📊 统计

三个周期，目标线，心情 × 效率。
样本不足时不下结论。
